# SimpleSignage プライバシーポリシー

最終更新：2026-10-07

SimpleSignage（以下「本アプリ」）は、店舗や事務所などで、画像・動画を画面に表示するためのアプリです。本アプリは、**利用者の個人情報を、開発者や第三者に送りません**。アカウント登録も、広告も、利用状況の解析（アナリティクス）もありません。

## 本アプリが端末に保存する情報

次の情報は、**利用者の端末の中だけ**に保存されます（開発者は受け取りません）。

- 表示する画像・動画（利用者が登録したもの）と、その表示の設定（スケジュール、画面分割、テロップの文言など）
- 管理画面にログインするための PIN、グループコード、操作を許可した端末の MAC アドレス

アプリを削除すると、これらは削除されます。

## 本アプリが通信する相手

本アプリは、次の通信だけを行います。

| 通信 | 目的 | 送る内容 |
| --- | --- | --- |
| 同じネットワーク内の端末・ブラウザ（LAN） | 管理画面の表示と、複数の端末の操作 | 設定、画像・動画、テロップなど（利用者が操作した内容）。PIN とグループコードで保護します |
| 気象庁（www.jma.go.jp） | 天気予報の表示（利用者が ON にしたとき） | 地域の予報データの取得のみ |
| 時刻サーバー（ntp.nict.jp など） | 時計のずれの補正（利用者が ON にしたとき） | 時刻の問い合わせのみ |
| 利用者が指定した Web ページ・ニュース（RSS）の URL | 区画への表示（利用者が設定したとき） | 指定された URL の取得のみ |

インターネット上の開発者のサーバーとの通信は、ありません。

## 端末の権限について

- **他のアプリの上に表示**：電源 ON 時に、自動で再生画面を開くために使います。
- **電池の最適化の除外・フォアグラウンド サービス・通知**：画面に出ていなくても、管理画面の通信を受け付け続けるために使います。
- **ネットワーク（Wi-Fi の状態・マルチキャスト）**：同じネットワークの端末を見つけるために使います。

## 子どもの利用

本アプリは、子どもを対象にしたものではなく、子どもから情報を集めることもありません。

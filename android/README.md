# サイネージ（Android 版）

端末内（または USB メモリ・SD カード）のフォルダにある画像・動画を一覧にして、全画面でループ再生するアプリです。

- 対応 OS: Android 8.0 以降（スマホ・タブレット・Android TV / STB）
- 画像: jpg / png / gif（アニメーション）/ webp / bmp / heic / avif
- 動画: mp4 / m4v / webm / mkv / 3gp / mov / ts（端末が対応するコーデックのみ）

## インストール

`dist/signage.apk` を端末にコピーしてファイルアプリから開くか、PC から次のコマンドでインストールします。

```
adb install -r dist\signage.apk
```

※ 初回は「提供元不明のアプリ」のインストール許可が必要です。

## 使い方

1. アプリを開き「フォルダを選択」で、再生したいフォルダを選んで「このフォルダを使用」→「許可」を押す
   - フォルダ選択画面が出ない・使えない端末（一部の Android TV / STB など）は
     「端末内のフォルダを直接選択」を押し、写真と動画へのアクセスを「すべて許可」して、
     アプリ内のブラウザでフォルダを選ぶ（内部ストレージ・SDカード・USBメモリに対応）
2. 表示秒数・画面の向き・シャッフルなどを設定
3. 「▶ 再生開始」

フォルダ内のファイルを追加・削除すると、ループが一周するたびに自動で反映されます（再起動は不要）。

### 再生中の操作

| 操作 | タッチ | リモコン |
|---|---|---|
| 次へ / 前へ | 左右スワイプ | ← → |
| 一時停止 / 再開 | ダブルタップ | 決定 |
| 情報表示 | タップ | ↑ ↓ |
| 設定画面へ | 長押し | 戻る / メニュー |

### 画面分割

管理画面の「画面分割」カード（端末名のすぐ下）で、画面を区画に分けて同時に表示できます。分割方法を絵のボタンで選び、プレビューの青い境界線をドラッグ（または境界線を選んで矢印キー）して比率を 5% 刻みで変えられます。各区画の表示内容（フォルダ／天気予報）もプレビュー内で選べ、「画面分割を保存」で再生画面にすぐ反映されます。カードは見出しをクリックして折りたたむこともできます（プレビューは横長画面のイメージです）。プレビューの下に、端末の画面サイズと、各区画にピッタリ収まる画像・動画の大きさ（px）と縦横比（例 16:9、8:9）が表示され、比率を動かすと一緒に更新されます。この縦横比・大きさで素材を用意すると、余白も切り取りもなく表示できます。

| 分割 | 区画 |
|---|---|
| 1画面 | 全画面 |
| 左右2分割 / 上下2分割 | 区画1・区画2 を指定した比率（20:80〜80:20）で |
| メイン＋サイド | 大きなメイン区画＋サイド区画2つ。横長画面ではサイドが右に縦並び、縦長画面では下に横並び。メインとサイドの比率（50:50〜85:15）、サイド同士の比率（20:80〜80:20）を選べます |

- 各区画の表示内容は「フォルダの画像・動画」「天気予報」から選べます
- フォルダの区画は、それぞれ別のフォルダを独立してループ再生します（区画1 のフォルダは「再生フォルダ」、区画2・3 は区画ごとに選択）
- 動画の音声・天気予報の差し込み・スワイプなどの操作は、最初のフォルダ区画（メイン）が対象です。他の区画の動画は無音で再生します
- 天気予報の区画は、日ごとの予報と3時間ごとの予報を交互に表示します。小さな区画では項目数を減らして表示します
- 複数の区画で同時に動画を再生すると、端末によっては動画デコーダーの数が足りず再生できないことがあります。その場合は動画を1区画だけにしてください

### 画像・動画のフィット確認

管理画面の「画面分割」カードにある「画像のフィットを確認」で、画像・動画が各区画にどう収まるかを、反映する前に確認できます。

- 端末の画面サイズと、画面分割カードの現在の設定（未保存の変更を含む）から、各区画の実際の大きさ（px・縦横比）を計算します
- 「確認する画像・動画を選ぶ」で選んだファイル（複数可・端末には送られません）を、区画ごとの縦横比で表示します。「この端末の画像も確認」で、端末に入っている画像（最大12枚）も確認できます
- 判定：✓ ピッタリ（縦横比のずれ 2% 以内）／ ✓ ほぼピッタリ（5% 以内）／ △ 余白・切り取りの割合を表示。画像が区画の1.5倍を超えて拡大される場合は「画像は小さめ」と表示します
- 表示方法（おまかせ／全体を表示＋ぼかし背景／画面いっぱい／全体を表示）を切り替えて見え方を比べられ、「この表示方法を端末に設定」でそのまま設定できます
- 「おまかせ」は再生画面と同じ判定です（切り取られる割合が 20% 以下なら画面いっぱい、それ以外はぼかし背景）
- 画面の向きが縦長の端末では、メイン＋サイドの区画の並びも縦横入れ替えて計算します

### 管理画面（別の端末から操作）

設定の「同じWi-FiのPC・スマホから操作できるようにする」を ON にすると、設定画面にアドレス（例 `http://192.168.1.23:8080/`）と PIN が表示されます。
同じネットワークの PC・スマホのブラウザでアドレスを開き、PIN を入力すると、再生中のまま次の操作ができます。

- 区画ごとのフォルダへの画像・動画のアップロード（複数選択・ドラッグ＆ドロップ、進捗表示）
- ファイルの一覧（サムネイル）・プレビュー・削除
- 設定の変更（画面分割・比率・区画の表示内容・表示秒数・時計・天気予報など）。保存すると再生画面にすぐ反映
- 「今すぐ反映」：フォルダを読み直して先頭から再生（アップロード・削除後は自動で反映することもできます）

アップロード・削除ができるのは、次のフォルダです。

| フォルダの選び方 | アップロード・削除 |
|---|---|
| 「フォルダを選択」（システムのフォルダ選択画面） | できる（v1.1.0 以降に選んだもの。以前に選んだフォルダは選び直してください） |
| 「アプリ専用フォルダを使う」 | できる（権限不要。アプリを削除すると中身も消えます） |
| 「端末内のフォルダを直接選択」 | 端末によってはできない（読み込み専用になります） |

#### 複数台の管理

どの端末の管理画面を開いても、同じネットワークにあるサイネージ端末が「端末一覧」に自動で表示されます（mDNS）。

- 一覧の端末をクリックすると、その端末のファイル・設定を操作できます
- チェックを付けた端末に、まとめて次の操作ができます
  - 今すぐ反映
  - ファイルを送る（区画を選んで、同じ画像・動画を全台に送る）
  - 設定を送る（右側の設定欄の内容を全台に適用）
  - PINをそろえる（全台を同じ PIN にする。以後は1回のログインで全台を操作できる）
- ルーターの設定などで自動で見つからない端末は「＋ 追加」から IP アドレスで追加できます
- 端末名（例：入口、レジ横）は、端末の設定画面か管理画面の「端末名を変更」で付けられます
- 端末ごとに PIN が違う場合は、一覧で「PIN が違います」と表示されるので、その端末を選んで PIN を入力してください（ブラウザに保存されます）

#### テロップ（流れる文字）

管理画面の「テロップを流す」から、再生中の画面に文字を流せます（お客様の呼び出し、閉店のご案内など）。
端末一覧でチェックした端末すべてに送れます（チェックがなければ選択中の端末）。

- 種類：通常（黒）／お知らせ（青）／呼び出し（赤）
- 流す回数：1〜5回、または「止めるまでずっと」（端末に保存され、再起動しても流れ続けます）
- 位置（画面の下・上）、文字の大きさ、速さ
- チャイム（ピンポーン）、読み上げ（端末が日本語の音声読み上げに対応している場合）
- 定型文：呼び出し・閉店のご案内・閉店時刻・タイムセール
- 「止めるまでずっと」のテロップを流している間に呼び出しなどを送ると、割り込んで流し、終わると元のテロップに戻ります

「予約テロップ」では、時刻と曜日（毎日・平日・土日など）を決めておくと自動で流れます（例：閉店30分前のご案内）。
予約は端末に保存され、管理画面を閉じていても流れます。「チェックした端末にコピー」で同じ予約をほかの端末にも設定できます。

安全のため、同じネットワーク（プライベートアドレス）からの接続だけを受け付け、PIN を5回続けて間違えると1分間操作できなくなります。PIN は設定画面の「PINを変更」で作り直せます。

### 画像・動画ごとの再生条件（日時を複数指定できます）

管理画面のファイル一覧で、ファイルごとに「条件」ボタンから再生する条件を付けられます。条件に合わない間、そのファイルだけ飛ばして再生し、ほかのファイルは今までどおりループします。

- **条件は複数追加できます（最大10個）。どれか1つに合うとき**に再生します。例：「土日の終日」と「12/24〜12/25 の 18:00〜22:00」
- 1つの条件の中では、設定した項目のすべてに合うときだけ合います（空欄の項目は条件なし）
  - **曜日**：チェックした曜日だけ（チェックなしは毎日）
  - **時間帯**：例）11:00〜14:00。終了が開始より前なら日をまたぎます（例：22:00〜02:00）
  - **期間**：例）12/1〜12/25（両端を含む）
- 中身のない条件は無視します。条件がひとつも無ければ、いつでも再生します。条件を付けたファイルには 🕒 と内容が表示されます（複数の条件は「／」で区切って表示）
- 全ファイルが条件外の時間帯は「いま再生する条件に合うファイルがありません」と表示し、時間が来ると再生を始めます
- 端末の時計（時刻・タイムゾーン）で判定します。条件は、ファイルを削除すると一緒に消えます。以前に設定した条件（1つだけのもの）もそのまま使えます

### 天気予報

設定の「一定間隔で天気予報を表示」を ON にし、地方・市区町村・間隔（分）・表示秒数を選ぶと、
ループの合間に気象庁の予報（今日・明日の天気・気温・6時間ごとの降水確率、週間予報）を全画面で表示します。

- 「3時間ごとの予報も続けて表示」が ON なら、続けて3時間ごとの天気・気温・風（24時間分）を表示します。
  横向きでは気温の変化をグラフで表示します（1画面あたりの秒数は同じ設定を使います）
- 画面の見出しには選んだ市区町村名（例：世田谷区の天気）を出します。
  気象庁の予報は「東京地方」などの地域単位のため、その市区町村を含む地域の予報を表示し、「予報区域：東京地方」と併記します
- 予報は30分ごとに取得し直します。通信できないときは前回取得した予報を表示し、一度も取得できていなければ飛ばします
- 「天気予報をプレビュー」で表示を確認できます
- 出典：気象庁ホームページ（画面右下に表示しています）

### 時計

「再生中に常に時計を表示」を ON にすると、画像・動画の上に日付と時刻を重ねて表示します。
位置（右上・右下・左上・左下）と大きさ（小・中・大）を選べます。天気予報の画面では、画面内に時計があるため重ねません。

### 画像・動画の表示方法（余白の扱い）

設定の「画像・動画の表示方法」（管理画面の「再生」からも変更可）で選べます。

| 表示方法 | 内容 |
|---|---|
| おまかせ（初期値） | 縦横比が近ければ画面いっぱいに表示（はみ出す部分を少し切り取る）。大きく違うときは全体を表示し、余白をぼかした背景で埋める |
| 全体を表示＋ぼかし背景 | 切り取らずに全体を表示し、余白は同じ画像をぼかして埋める |
| 画面いっぱい | 余白なし。はみ出す部分は切り取る |
| 全体を表示 | 余白は黒 |

動画は背景をぼかせないため、「ぼかし背景」になる場合は黒い余白になります。

### 動画が途中で止まる・固まる場合

業務用サイネージの専用ボードなど、機種によっては動画が途中で止まることがあります。

- 再生位置が12秒以上進まないときは、自動でその位置から読み込み直し、それでも進まなければ次の項目へ進みます
- それでも止まる場合は、設定の「動画の互換モード」を ON にしてください（管理画面の「再生」からも変更できます）。動画の描画方式を切り替えます
- 4K や高ビットレートの動画は、フル HD（1920×1080）・H.264 の mp4 に変換すると安定します

### 電源 ON 時の自動再生

設定の「自動再生」を ON にすると:

- アプリアイコンから起動したとき、設定画面を飛ばしてすぐに再生を始めます
- 端末の電源 ON 時に自動で再生画面を開きます。
  これには「他のアプリの上に重ねて表示」の許可が必要です（スイッチを ON にすると案内が出ます）

※ メーカー独自の省電力機能で自動起動が止められる機種があります。その場合は端末の設定で「自動起動」を許可してください。

## ビルド

`build.bat` を実行すると `dist/signage.apk` を出力します。
Android Studio で `android` フォルダを開いてもビルドできます。

## ファイル構成

- `PlayerActivity.kt` — 再生画面（区画の配置・時計・操作）
- `MediaZone.kt` — 区画ごとのループ再生（画像は ImageDecoder、動画は Media3 ExoPlayer）
- `PanelZones.kt` — 天気予報の区画
- `AdminServer.kt` / `FolderStore.kt` / `assets/admin.html` — 管理画面（Web サーバー・フォルダへの書き込み・画面）
- `AdminService.kt` — 管理画面を常駐させるフォアグラウンドサービス
- `Peers.kt` — 同じネットワークのサイネージ端末の検出（mDNS / DNS-SD）
- `Ticker.kt` / `TickerView.kt` — テロップ（送信・予約・表示・チャイム・読み上げ）
- `RemoteFocus.kt` — テレビのリモコン操作向けの表示（フォーカス枠・中央寄せ）
- `MainActivity.kt` — 設定画面・フォルダ選択（Storage Access Framework）
- `MediaScanner.kt` — フォルダ内の画像・動画の一覧化（サブフォルダ対応・自然順ソート）
- `BootReceiver.kt` — 電源 ON 時の自動起動
- `FolderBrowser.kt` — フォルダ選択画面が無い端末向けのアプリ内フォルダブラウザ
- `Weather.kt` — 気象庁の予報データ（日ごと・3時間ごと）の取得・解析
- `WeatherView.kt` / `TimeSeriesView.kt` / `PanelView.kt` — 天気予報の画面（日ごと・3時間ごと・共通部品）

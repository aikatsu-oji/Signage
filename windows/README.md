# サイネージ（Windows 版）

Windows PC でフォルダの画像・動画を全画面でループ再生します。Android 版と同じ機能を持ち、同じ管理画面から操作できます。

- 対応 OS: Windows 10 / 11（Microsoft Edge を使います）
- 画像: jpg / png / gif / webp / bmp / avif / svg
- 動画: mp4 / webm / m4v / mov / mkv（Edge が再生できる形式。mp4（H.264）がおすすめ）

## 使い方

1. `Signage.exe` をダブルクリックします（インストールは不要です）
   - 初回は Windows のファイアウォールの確認が出ます。別の端末から管理画面を使うため「プライベート ネットワーク」を許可してください
   - Windows SmartScreen の警告が出た場合は「詳細情報」→「実行」を選んでください（署名していないため）
2. Edge が全画面（キオスクモード）で開き、再生が始まります
3. 画像・動画は `ユーザーフォルダ\Signage\zone1` に入れるか、管理画面からアップロードします

タスクトレイのアイコン（青い画面のマーク）から次の操作ができます。

| メニュー | 内容 |
|---|---|
| 設定を開く | この PC の設定（フォルダ・モニター・天気の地域・端末名・PIN） |
| 再生画面を開く / 閉じる | 全画面の再生を開始・終了 |
| 管理画面を開く | 画面分割・表示秒数・時計・テロップなどの設定、ファイルの管理 |
| Windows の起動時に自動で開始 | サインインしたら自動で再生を始める |
| 終了 | アプリを終了 |

全画面の再生画面は `Alt + F4` で閉じられます。再生中は画面の消灯・スリープを止めます。

### 再生中のキー操作

| キー | 操作 |
|---|---|
| → / ← | 次へ / 前へ |
| Space | 一時停止 / 再開 |
| I | 情報表示 |

## 画像・動画ごとの再生条件（日時を複数指定できます）

管理画面のファイル一覧で、ファイルごとに「条件」ボタンから再生する条件を付けられます。条件に合わない間、そのファイルだけ飛ばして再生し、ほかのファイルは今までどおりループします。

- **条件は複数追加できます（最大10個）。どれか1つに合うとき**に再生します。例：「土日の終日」と「12/24〜12/25 の 18:00〜22:00」
- 1つの条件の中では、設定した項目のすべてに合うときだけ合います（空欄の項目は条件なし）
  - **曜日**：チェックした曜日だけ（チェックなしは毎日）
  - **時間帯**：例）11:00〜14:00。終了が開始より前なら日をまたぎます（例：22:00〜02:00）
  - **期間**：例）12/1〜12/25（両端を含む）
- 中身のない条件は無視します。条件がひとつも無ければ、いつでも再生します。条件を付けたファイルには 🕒 と内容が表示されます（複数の条件は「／」で区切って表示）
- 全ファイルが条件外の時間帯は「いま再生する条件に合うファイルがありません」と表示し、時間が来ると再生を始めます
- 端末の時計（時刻・タイムゾーン）で判定します。条件は、ファイルを削除すると一緒に消えます。以前に設定した条件（1つだけのもの）もそのまま使えます

## 画像・動画のフィット確認

管理画面の「画面分割」カードにある「画像のフィットを確認」で、画像・動画が各区画にどう収まるかを、反映する前に確認できます。

- 端末の画面サイズと、画面分割カードの現在の設定（未保存の変更を含む）から、各区画の実際の大きさ（px・縦横比）を計算します
- 「確認する画像・動画を選ぶ」で選んだファイル（複数可・端末には送られません）を、区画ごとの縦横比で表示します。「この端末の画像も確認」で、端末に入っている画像（最大12枚）も確認できます
- 判定：✓ ピッタリ（縦横比のずれ 2% 以内）／ ✓ ほぼピッタリ（5% 以内）／ △ 余白・切り取りの割合を表示。画像が区画の1.5倍を超えて拡大される場合は「画像は小さめ」と表示します
- 表示方法（おまかせ／全体を表示＋ぼかし背景／画面いっぱい／全体を表示）を切り替えて見え方を比べられ、「この表示方法を端末に設定」でそのまま設定できます
- 「おまかせ」は再生画面と同じ判定です（切り取られる割合が 20% 以下なら画面いっぱい、それ以外はぼかし背景）
- 画面の向きが縦長の端末では、メイン＋サイドの区画の並びも縦横入れ替えて計算します

## 管理画面・複数台の管理

Android 版と同じ管理画面（`http://この PC の IP:8080/`）です。PIN は「設定を開く」で確認・変更できます。
同じネットワークの Android 版・Windows 版の端末が「端末一覧」に自動で表示され、まとめて操作できます
（ファイルの送信・設定の送信・テロップ・予約テロップ・PIN の統一）。

## 設定ファイルの場所

- 設定: `%APPDATA%\Signage\config.json`
- 天気予報のキャッシュ: `%APPDATA%\Signage\cache`
- 再生用の Edge のプロファイル: `%APPDATA%\Signage\edge`（普段使いの Edge とは別）

## ビルド

Python 3.10 以降をインストールし、`build.bat` を実行すると `..\dist\Signage.exe` を出力します。

開発中は次のように起動できます。

```
.venv\Scripts\python app.py --no-player   # 再生画面を開かずに起動
```

## ファイル構成

- `app.py` — 常駐アプリ（タスクトレイ・Edge の起動・自動開始・スリープ防止・予約テロップの時刻確認）
- `server.py` — Web サーバー（管理画面の API は Android 版と共通）
- `store.py` — 設定・フォルダ・テロップの管理
- `weather.py` — 気象庁の予報データの取得・解析
- `peers.py` — 同じネットワークのサイネージ端末の検出（mDNS）
- `web/player.html` — 再生画面、`web/settings.html` — この PC の設定画面
- 管理画面 `web/admin.html` はビルド時に Android 版からコピーします

# サイネージ（Windows 版）

Windows PC でフォルダの画像・動画を全画面でループ再生します。Android 版と同じ機能を持ち、同じ管理画面から操作できます。

- 対応 OS: Windows 10 / 11（Microsoft Edge を使います）
- 画像: jpg / png / gif / webp / bmp / avif / svg
- 動画: mp4 / webm / m4v / mov / mkv（Edge が再生できる形式。mp4（H.264）がおすすめ）

## 使い方

1. [Releases](https://github.com/aikatsu-oji/Signage/releases) の最新のリリースから `Signage-windows-<版>.exe` をダウンロードし、ダブルクリックします（インストールは不要です。同じリリースの `SHA256SUMS` でファイルを確かめられます）
   - 初回は Windows のファイアウォールの確認が出ます。別の端末から管理画面を使うため「プライベート ネットワーク」を許可してください
   - Windows SmartScreen の警告が出た場合は「詳細情報」→「実行」を選んでください（署名していないため）
2. 「Windows の起動時に自動で開始」が **ON** のときは、Edge が全画面（キオスクモード）で開き、再生が始まります。**OFF**（初期状態）のときは全画面にはならず、タスクトレイに常駐します。再生はトレイのアイコンの「再生画面を開く（全画面）」から始めます（初回起動時は設定画面が開きます）
3. 画像・動画は `ユーザーフォルダ\Signage\zone1` に入れるか、管理画面からアップロードします

タスクトレイのアイコン（青い画面のマーク）から次の操作ができます。

| メニュー | 内容 |
|---|---|
| 設定を開く | この PC の設定（フォルダ・モニター・天気の地域・端末名・PIN） |
| 再生画面を開く / 閉じる | 全画面の再生を開始・終了 |
| 表示するモニター | 再生画面を出すモニターを切り替える（再生画面が開いていれば、選んだモニターで開き直す） |
| 管理画面を開く | 画面分割・表示秒数・時計・テロップなどの設定、ファイルの管理 |
| Windows の起動時に自動で開始 | サインインしたら自動で再生を始める |
| 終了 | アプリを終了 |

全画面の再生画面は `Alt + F4` で閉じられます。再生中は画面の消灯・スリープを止めます。

### 再生中のキー操作

| キー | 操作 |
|---|---|
| → / ← | 次へ / 前へ |
| Space | 一時停止 / 再開 |
| I | 情報表示 |

## 表示するモニターの切り替え

複数のモニターがあるときは、再生画面を出すモニターを選べます。

- **トレイのアイコン →「表示するモニター」**から選びます（チェックが現在のモニターです）。再生画面が開いていれば、選んだモニターで開き直します
- 設定画面の「表示するモニター」を変えて保存しても、同じように開き直します
- 画面の拡大率（DPI）が違うモニターを混ぜていても、開いたあとに位置を確かめて、選んだモニターに合わせます
- モニターの番号は、メイン（Windows の主モニター）が 1、残りは左から右・上から下の順です。Windows の「ディスプレイ設定」の番号とは違うことがあります。解像度（例：1920×1080）を目安に選んでください
- うまく切り替わらないときは、`%APPDATA%\Signage\signage.log` を見てください。開くときに選んだモニターの位置と、ウィンドウの実際の位置が記録されています

## 新しい版への入れ替え

Signage は二重起動しません。古い版が動いたまま新しい exe を起動すると、「サイネージはすでに起動しています」と、実行中の版とこのファイルの版が表示されます（同じ版のときは設定画面が開きます）。入れ替えるときは次の順に行います。

1. タスクトレイの Signage のアイコンを右クリックして「終了」を押します
2. 新しい exe を起動します
3. 管理画面の端末名の下の「接続中 v…」や、トレイのアイコンにマウスを置いたときの表示で、版を確認できます

「Windows の起動時に自動で開始」が ON の場合は、exe を置いた場所を登録しています。ファイルを移動・入れ替えたあと、起動し直せば登録し直されます。

## 画像・動画ごとの再生条件（日時を複数指定できます）

管理画面のファイル一覧で、ファイルごとに「条件」ボタンから再生する条件を付けられます。条件に合わない間、そのファイルだけ飛ばして再生し、ほかのファイルは今までどおりループします。

- **条件は複数追加できます（最大10個）。どれか1つに合うとき**に再生します。例：「土日の終日」と「12/24〜12/25 の 18:00〜22:00」
- 1つの条件の中では、設定した項目のすべてに合うときだけ合います（空欄の項目は条件なし）
  - **曜日**：チェックした曜日だけ（チェックなしは毎日）
  - **時間帯**：例）11:00〜14:00。終了が開始より前なら日をまたぎます（例：22:00〜02:00）
  - **期間**：例）12/1〜12/25（両端を含む）
- 中身のない条件は無視します。条件がひとつも無ければ、いつでも再生します。条件を付けたファイルには 🕒 と内容が表示されます（複数の条件は「／」で区切って表示）
- 全ファイルが条件外の時間帯は「いま再生する条件に合うファイルがありません」と表示し、時間が来ると再生を始めます
- 端末の時計（時刻・タイムゾーン）で判定します。条件は、ファイルを削除すると一緒に消えます。以前に設定した条件（1つだけのもの）もそのまま使えます

## 画面の向き（縦置き・横置き）

管理画面の「画面分割」カードの「画面の向き」で、縦向き・横向きを選ぶと、プレビューと各区画に必要な画像サイズがその向きで表示されます（メイン＋サイドは、横向きではメインが左・サイドが右、縦向きではメインが上・サイドが下になります）。

- Windows 版の画面の向きは、**Windows のディスプレイ設定**（画面の向き）で決まります。アプリからは回転できません。管理画面での選択は、縦置きにする前の素材づくりや確認用です
- 再生画面は、実際のモニターの縦横に合わせて自動で並びます（「自動」のまま使えます）
- 画面の向きは、端末を置く向きによって違うため、設定のエクスポート・一括反映には含まれません

## 画像・動画のフィット確認

管理画面の「画面分割」カードにある「画像のフィットを確認」で、画像・動画が各区画にどう収まるかを、反映する前に確認できます。

- 端末の画面サイズと、画面分割カードの現在の設定（未保存の変更を含む）から、各区画の実際の大きさ（px・縦横比）を計算します
- 「確認する画像・動画を選ぶ」で選んだファイル（複数可・端末には送られません）を、区画ごとの縦横比で表示します。「この端末の画像も確認」で、端末に入っている画像（最大12枚）も確認できます
- 判定：✓ ピッタリ（縦横比のずれ 2% 以内）／ ✓ ほぼピッタリ（5% 以内）／ △ 余白・切り取りの割合を表示。画像が区画の1.5倍を超えて拡大される場合は「画像は小さめ」と表示します
- 表示方法（おまかせ／全体を表示＋ぼかし背景／画面いっぱい／全体を表示）を切り替えて見え方を比べられ、「この表示方法を端末に設定」でそのまま設定できます
- 「おまかせ」は再生画面と同じ判定です（切り取られる割合が 20% 以下なら画面いっぱい、それ以外はぼかし背景）
- 画面の向きが縦長の端末では、メイン＋サイドの区画の並びも縦横入れ替えて計算します

## 設定のエクスポートと一括反映（他の端末へまとめてコピー）

ある端末の設定をファイルに保存し、別の端末（複数可）へまとめて反映できます。同じ設定の端末を何台も用意するときに使います。

1. **エクスポート**：端末一覧で元にする端末（この端末でも、自動検出・手動追加した他の端末でも）を選び、「設定をエクスポート」を押すと、`signage-settings_端末名_日付.json` がダウンロードされます
2. **反映**：「設定ファイルから反映」を押し、ファイルを選びます。反映する内容と反映先の端末（初期は、一覧でチェックした端末。チェックがなければ選択中の端末）を選んで「反映する」を押すと、端末ごとに結果が表示されます

- 含まれるもの：設定（画面分割・区画の表示内容・再生・時計・天気予報の間隔）、予約テロップ、画像・動画ごとの再生条件
- 含まれないもの：フォルダ、端末名、PIN、天気予報の地域、画像・動画のファイル本体（端末ごとに違うため）。ファイル本体は「ファイルを送る」で送れます
- 予約テロップは、反映先の予約がファイルの内容に置き換わります。再生条件は、反映先に同じ区画・同じファイル名のファイルがあるものだけ反映します（無いものは省略して、件数を表示します）
- Android 版と Windows 版の間でも使えます（片方にしかない設定項目は無視されます）
- ファイルの中身は読みやすい JSON です。特定の項目だけ変えたいときは、ファイルを編集してから反映することもできます

## マイクで声を届ける（管理画面から放送）

管理画面の「マイクで声を届ける」で、PC のマイクの声を、選んだ端末のスピーカーからすぐ流せます（お客様の呼び出しや案内など）。

- **使い方**：放送先の端末を一覧でチェック（チェックが無ければ選択中の端末）し、「🎤 押している間、話す」を押したまま話して、離すと止まります。「ボタンを押さなくても話し続ける」にチェックすると、ボタンを押すたびに開始・停止できます。スペースキー／Enter キーを押している間でも話せます
- **使える場所**：ブラウザは、**https のページか localhost で開いたページ**でしかマイクを使わせません。管理に使う PC で **Windows 版 Signage を起動し**（タスクトレイに常駐するだけで構いません）、同じ PC のブラウザで **`http://localhost:8080/`** を開いてください。`http://192.168.x.x:8080/` のように IP アドレスで開いたページ（スマホを含む）では、マイクは使えません（画面に案内が表示されます）
- **声が届かないとき**：「テスト音を送る」を押すと、声を出さずに、放送先の端末までテスト音（ピー音）が届くか確かめられます。マイクが使えない（IP アドレスで開いた）ページからも使えます。結果は放送先の端末ごとに画面に残り、失敗したときはその理由、端末のメディア音量が 0 のとき、Windows 版の再生画面が開いていないときも表示します。次の点も確認してください
  - 放送先の端末を一覧でチェックしているか（チェックがなければ、選択中の端末に送ります。選択中が「この端末」だと、この PC から鳴ります）
  - 端末のアプリが最新版か（古い版は放送を受け取れません）。端末のメディア音量が 0 でないか
- 放送先は、同じネットワークの Android 版・Windows 版の端末です（複数台へ同時に送れます）。声は 0.2 秒ぶんずつ送るため、遅れは 1 秒前後です
- 放送中は、端末の画面に「📢 放送中」を表示し、動画の音を小さくします。終わると元に戻ります
- **Windows 版は、再生画面が開いているときだけ鳴ります**（再生画面が閉じている端末には「再生画面が開いていないため、声が出ません」と表示します）。Android 版は、アプリが動いていれば画面の状態にかかわらず鳴ります
- PIN は他の操作と同じく必要です。ハウリングを防ぐため、管理する PC は端末から離すか、ヘッドセットを使ってください

## 管理画面・複数台の管理

Android 版と同じ管理画面（`http://この PC の IP:8080/`）です。PIN は「設定を開く」で確認・変更できます。
同じネットワークの Android 版・Windows 版の端末が「端末一覧」に自動で表示され、まとめて操作できます
（ファイルの送信・設定の送信・テロップ・予約テロップ・PIN の統一）。

### 管理画面に入れる端末の制限（MAC アドレス）
管理画面の「管理画面に入れる端末」で、スマホ・PC を MAC アドレスで登録すると、登録した端末だけが管理画面を操作できます。ここで決めた内容は、見つかっているサイネージ端末すべてに反映されます（端末ごとの設定ではありません）。
- 初期状態は制限なしです。「この端末を追加」で、いま操作している端末の MAC アドレスを登録できます（手入力も可）。
- 制限を ON にするとき、いま操作している端末が登録されていないと断ります（締め出し防止）。
- スマホの Wi-Fi「プライベート アドレス（ランダム MAC）」が有効だと、Wi-Fi ごとに MAC アドレスが変わります。「この端末を追加」で登録すると、実際に使われているものを登録できます。
- VPN（Tailscale）経由は MAC アドレスを確認できないため、「VPN 経由の操作は許可する」で決めます（既定は許可）。
- **解除（リセット）**：誰も操作できなくなったら、この PC のタスクトレイ「操作できる端末の制限を解除」、または設定画面の「制限を解除する」で、制限と登録の一覧を消せます。この PC 自身からの操作は、制限中でも常に許可されます。

### 管理画面の使いやすさ
- **テロップのボタンを変更できます。** 「ボタンを編集」で、名前・文言・種類・回数・チャイム・読み上げを変えたり、並べ替え・追加・削除（最大12個）・初期状態に戻すことができます。「＋ いまの内容をボタンに保存」で、入力中の内容をそのままボタンにできます。予約テロップのボタンも同じです。ボタンは、使っているブラウザに保存されます。
- テロップは Ctrl + Enter で流せます。文字数の表示と、最近流した文言（6件）から再入力もできます。文字が空のときは「流す」を押せません。
- 画面上部の「テロップ／マイク／画像・動画／画面分割／予約テロップ／設定／入れる端末」から、各項目へ移動できます。

### 天気予報の地域を管理画面から設定
管理画面の「設定」の「天気予報」で、地方（都道府県）と市区町村を選べます。端末の設定画面に行かなくても変更でき、「設定を送る」でチェックした端末にまとめて反映もできます（地域の一覧は、端末がインターネットに接続できるときに取得されます）。

### 管理画面の画面構成
- 左に「端末一覧」だけを独立して置きました。**チェック**＝テロップ・マイク・まとめ操作の送信先、**名前をクリック**＝その端末の設定を開く、です。
- 右は 3 つのタブです：「📣 送る（テロップ・マイク）」「⚙ 端末の設定」「🔒 入れる端末」。
- テロップとマイクには、それぞれ「送信先」の選択ボタンがあり、その場で端末を選べます（端末一覧のチェックと連動します。「全部」「解除」もあります）。何も選んでいないときは、設定を開いている端末だけに送ることを表示します。

### 配信状況のモニタリング
管理画面の「📊 配信状況」タブで、見つかっているすべての端末の状況を、5 秒ごとに確認できます。
- **正常／注意／異常**を端末ごとに表示します。異常：応答なし、再生画面が止まっている、空き容量がほとんどない（200 MB 未満）。注意：PIN が違う、再生できるファイルがない、空き容量が少ない（1 GB 未満）。
- 再生画面が動いているか、区画ごとに**いま再生中のファイル名と位置**、テロップの状態、空き容量、稼働時間、アプリのバージョンを表示します。
- 異常・注意の件数はタブ名と、ブラウザのタブのタイトルにも出ます（他のタブを見ている間は 30 秒ごとに確認）。状態が変わったときは「最近の出来事」に記録します（このページを開いている間の記録です）。
- 再生中のファイル名は、再生画面が 5 秒ごとに知らせる内容です。古い版の端末は「配信状況の確認に未対応」と表示されるので、更新してください。

### Android 端末のアプリ（APK）更新
Android 端末のアプリ更新は、管理画面の「📊 配信状況」タブから行えます（詳しくは Android 版の README）。Windows 版は、新しい exe に差し替えてください（「新しい版への入れ替え」を参照）。

### 配信状況の「監視対象外」
夜間に電源を切る端末など、異常として数えたくない端末は、「📊 配信状況」タブの端末のカードの「監視対象外にする」で外せます。外した端末は、「監視対象外の端末」に分けて表示され、異常の件数・タブの表示・出来事の記録に含まれません（「監視に戻す」で戻せます）。この設定は、使っているブラウザに保存されます（別の PC・スマホには引き継がれません）。オフラインの端末も指定できます。

## 設定ファイルの場所

- 設定: `%APPDATA%\Signage\config.json`
- 天気予報のキャッシュ: `%APPDATA%\Signage\cache`
- 再生用の Edge のプロファイル: `%APPDATA%\Signage\edge`（普段使いの Edge とは別）

## ビルド

Python 3.10 以降をインストールし、`build.bat` を実行すると `..\dist\Signage.exe` を出力します（管理画面 `admin.html` は Android 版からコピーされます）。
リリースの出し方は [docs/RELEASING.md](../docs/RELEASING.md) を参照してください。

開発中は次のように起動できます。

```
.venv\Scripts\python app.py --no-player   # 再生画面を開かずに起動
```

## ファイル構成

| ファイル | 内容 |
|---|---|
| `app.py` | 常駐アプリ（タスクトレイ・Edge の起動とモニターの切り替え・自動開始・スリープ防止・予約テロップの時刻確認） |
| `server.py` | Web サーバー（管理画面の API は Android 版と共通） |
| `store.py` | 設定・フォルダ・テロップ・再生条件の管理 |
| `weather.py` | 気象庁の予報データの取得・解析 |
| `peers.py` | 同じネットワークのサイネージ端末の検出（mDNS） |
| `devices.py` | 管理画面に入れる端末の制限（MAC アドレス） |
| `guard.py` | 管理画面への接続の検査（Host・Origin） |
| `instance.py` | 二重起動の確認 |
| `placement.py` | 再生画面を出すモニターの選択と、ウィンドウ位置の判定 |
| `web/player.html` / `web/settings.html` | 再生画面 / この PC の設定画面 |
| `web/admin.html` | 管理画面（ビルド時に Android 版からコピー） |

## 画面分割の比率を自由に決める（縦長の画面に 16:9 の動画など）
管理画面の「画面分割」で、比率を 1% 刻みで決められ（メインは 20〜90%）、「区画の縦横比を合わせる」で、縦長の画面のメインに 16:9 をぴったり合わせるなど、縦横比から比率を自動で計算できます。

## 動画のサムネイル
管理画面のファイル一覧で、動画も 1 コマ（先頭付近）をサムネイルに表示します（管理画面を開いている PC・スマホのブラウザが、動画の一部を読み込んで作ります）。40 MB を超える動画は先頭の 4 MB だけを読むため、動画によっては作れず、「▶」の表示のままになります。表示方法の確認の画面でも、動画が黒画面にならず最初のコマを表示します。

## 画像・動画の回転（向きが違うとき）
管理画面のファイル一覧の各ファイルの「回転」を押すと、サイネージでの表示が 90 度ずつ回ります（0° → 90° → 180° → 270° → 元に戻る）。スマホで撮った動画が横倒しや逆さまに映るときや、縦向き・横向きの画面に合わせて動画を回したいときに使います。サムネイルにも反映されます。回転した画像・動画は、回したあとの向きで画面に収まるように表示します（表示方法の設定も、回したあとの縦横比で判断します）。

## Web ページ・ニュース（RSS）の区画
画面分割の区画の表示内容に、「**Web ページ**」と「**ニュース（RSS）**」を選べます（管理画面の「端末の設定」→「画面分割」で区画の種類を選んで保存すると、その区画の URL と読み直す間隔を設定できます）。
- **Web ページ**：指定した URL のページを表示し、設定した間隔（分）で読み直します。ページ側が埋め込みを禁止している場合（銀行・SNS など）は表示されません。
- **ニュース（RSS）**：RSS 2.0 / Atom の見出しを、4〜5 件ずつ 10 秒ごとに切り替えて表示し、設定した間隔で再取得します。取得はこの PC が行います（この PC 自身や、169.254.x.x のアドレスは指定できません）。
- URL は http:// か https:// だけ指定できます。取得できないときは、1 分ごとに再試行します。

## HTTPS について
HTTPS（暗号化）への対応は、1.8.20 / Android 1.9.22 で取りやめました。通信は HTTP のみです。信頼できるネットワークで使い、グループコード・PIN を設定してください（SECURITY.md 参照）。

## グループ（組織）コード
管理画面の「🔒 入れる端末」タブの「グループ（組織）コード」で、全端末に同じコードを設定すると、**コードを知る管理画面だけ**が操作できます（PIN に加えて必要）。同じネットワークにある別のグループのサイネージは、端末一覧に出なくなります。
- コードは、英数字と - _ の 8〜32 文字です。設定すると、このブラウザがコードを覚え、別の PC・スマホからは、ログインのときに入力します。
- 設定できなかった端末は、別のグループになります。戻ったら、もう一度設定してください。
- 忘れたときは、この PC の設定画面の「グループコード」の「解除」で、解除できます。
- 通信は暗号化されないため、信頼できるネットワークで使ってください。

## 【1.8.14 以降】グループコードが未設定だと、この PC 自身からしか操作できません
グループコードを決めるまで、LAN の別の端末（スマホ・別の PC）の管理画面からは、この PC を操作できません（この PC のブラウザの管理画面は、そのまま使えます）。**アップデートする前に、設定画面でグループコードを決めてください**（管理画面の「入れる端末」タブからまとめて設定するのが簡単です）。

## アプリの時刻を、この PC の設定と別にする
管理画面の「端末の設定」の「時計」で、次の 3 つを、この PC のシステムの設定とは別に決められます。
- **時刻の形式**：24 時間（15:30）／12 時間（午後3:30）
- **タイムゾーン**：日本、韓国、中国、アメリカ各地、UTC など（「この端末の設定に合わせる」が初期値）
- **時刻のずれの補正**：分単位（この PC の時計が遅れているときは＋）
アプリの時計の表示、ファイルの再生条件（時間帯・曜日・期間）、予約テロップの時刻に反映されます（天気予報の時刻は、予報の発表に合わせて日本時間です）。設定画面の下に、「いま、アプリは○○と考えています」と表示されます。

## 時刻サーバーへの定期的な問い合わせ
この PC を長く動かしていると、時計がずれることがあります。そのため、アプリは、**1 時間ごと**（起動時にも、失敗したときは 5 分ごと）に、時刻サーバーに問い合わせて、アプリの時刻を合わせます（初期は ON）。
- 初期の時刻サーバーは、`ntp.nict.jp`（情報通信研究機構）です。管理画面の「時計」で変えられます。
- NTP（UDP の 123 番）が塞がれたネットワークでは、HTTPS の応答の Date ヘッダーで代わりに合わせます（精度は約 1 秒）。
- 合わせるのは、アプリの時刻（時計の表示・再生条件・予約テロップ）だけです。この PC のシステムの時計は、変えません。
- 「今すぐ時刻サーバーに問い合わせる」で、すぐに確かめられます。最後に合わせた時刻と、ずれの大きさが表示されます。
- 手動の補正（分）は、時刻サーバーとの差に、さらに足されます。同期を使うときは、通常は 0 のままにしてください。

## 端末が一覧に出ないとき（グループコード）
同じグループのはずの端末が、端末一覧に出ないときは、管理画面の左の「端末一覧」の下に、**「見つかりましたが、一覧に出していない端末：○○（理由）」**と出ていないかを見てください（1.9.19 以降）。理由は次のとおりです。
- **グループ未設定、または、古い版**：その端末で、グループコードを決めてください（Fire TV はリモコンで、設定画面の「グループコードを設定」）。1.9.14 より古い版は、グループコードに対応していないため、この表示になります（アプリを更新してください）。
- **別のグループ**：その端末のコードが、ほかの端末と違います。コードを決め直してください。
- **グループを設定している端末（この端末は未設定）**：見ている管理画面の端末が、未設定です。
- **何も出ない**：ネットワークの問題です（同じ Wi-Fi・LAN か、端末が起動していて、管理画面が ON か、ルーターが機器間の通信を遮断していないか）。IP アドレスで「＋追加」すれば、一覧に出なくても追加できます（ただし、グループコードが合っている必要があります）。

## 「応答なし」のときの診断
端末の欄に「端末に接続できません」と出たときは、**「接続を診断する」**を押してください（1.8.19 以降）。その端末の IP の、ポート 8080〜8089 に、HTTP で届くかを調べて、次のように案内します。
- 別のポートで届いたとき：そのポートに、ワンクリックで切り替えられます（ポートは、使用中だと 8081 などになります）。
- どのポートにも届かないとき：端末の設定（管理画面が ON か）、電源とアプリ（Fire TV はスリープ中に届かないことがあります）、ネットワーク、HTTPS の可能性、を順に確認する案内が出ます。HTTP と HTTPS の両方を、新しいタブで直接開くリンクも出ます。

## 端末の自動検出（UDP ブロードキャスト）
mDNS が通らない機種（Fire TV など）でも端末を見つけられるよう、5 秒ごとに UDP（ポート 48080）で自分の存在を知らせ、ほかの端末の知らせを聞きます（1.8.21 以降・Android 1.9.23 以降）。20 秒聞こえなくなると、一覧から消えます。グループコードの扱いは mDNS と同じです。ルーターが機器間通信（AP アイソレーション）や UDP ブロードキャストを遮断していると、見つかりません（その場合は IP アドレスで追加してください）。Windows のファイアウォールで、UDP 48080 の受信を許可する必要がある場合があります。

## 左右3分割・上下3分割（1.8.22 以降 / Android 1.9.25 以降）
画面の分割に、**左右3分割（左・中・右の3列）**と**上下3分割（上・中・下の3段）**を追加しました。3つの区画は等分です（比率の変更はありません）。管理画面の「端末の設定」→「画面分割」、または Android の設定画面から選べます。区画の表示内容（画像・動画／天気予報／Web ページ／RSS）は、これまでと同じように区画ごとに選べます。


※ 1.8.25 / Android 1.9.28 で、呼び名を「**左右3分割**（左・中・右の3列）」「**上下3分割**（上・中・下の3段）」に改めました（既存の左右2分割・上下2分割と同じ呼び方です。区画の並びは変わりません）。

## 3分割の比率の変更（1.8.26 以降 / Android 1.9.29 以降）
左右3分割・上下3分割でも、管理画面の画面分割のプレビューで、**青い境界線2本をドラッグ**（またはクリックして ←→↑↓ キー、Shift で 5% ずつ）すると、区画1・区画2の大きさを変えられます（区画3は残り。各区画 10% 以上）。初期値は 33 : 33 : 34 です。Android の設定画面では、区画1・区画2の大きさをそれぞれ選びます。あわせて、3分割のとき区画2・3の表示内容（フォルダ・URL など）が管理画面に出ない不具合を直しました。

## 天気予報：地方ごとの一覧（1.8.28 以降 / Android 1.9.31 以降）
天気予報に、**地方ごとの一覧画面**を追加できます。日本地図のように、その地方の府県（全国は主要 10 都市）の天気・気温・降水確率を、位置に合わせたタイルで 1 画面に並べます（晴れ＝オレンジ、くもり＝グレー、雨＝青、雪＝水色）。
- 管理画面の「端末の設定」→「天気予報」→「**地方ごとの一覧**」で、表示したい地方（全国・北海道・東北・関東甲信・北陸・東海・近畿・中国・四国・九州・沖縄）を選びます（複数可）。「一覧に出す日」は、きょう／あした／両方から選べます。「この端末に保存」で反映されます。
- 再生画面では、設定した地域（日ごと → 3時間ごと）のあとに、選んだ地方の一覧を順に表示します。地域を設定せず、一覧だけを表示することもできます。

## 地方ごとの一覧に、地図の背景（Windows 1.8.29 / Android 1.9.32 以降）
地方ごとの一覧の背景に、日本の都道府県の地図を表示します（その地方の府県は明るく塗ります）。タイルは、府県の実際の位置に置き、重なるときは、少しずらして、実際の位置から線で結びます。タイルが多い地方（全国など）は、地図が隠れないよう、タイルを小さくします。全国は、沖縄のタイルを左下に置きます。地図は、Natural Earth（パブリックドメイン）のデータを簡略化したものです。

## 画像・動画の保存方法が「ライブラリ」になりました（1.9.0 以降 / Android 1.10.0 以降）
- 画像・動画は、アプリ専用の保存場所 **ライブラリ**（`%USERPROFILE%\Signage\library`）に、まとめて保存されます。区画ごとのフォルダ・任意のフォルダの指定は、**廃止**しました（設定画面の「フォルダを開く」は、ライブラリを開きます）。
- どの区画で流すかは、**配置**で決まります。管理画面から区画に画像・動画を追加すると、ライブラリに保存され、その区画に配置されます。区画から削除すると配置が外れ、どの区画にも使われなくなったファイルは、ライブラリからも消えます。同じファイルを複数の区画に置けるようにする画面は、今後のバージョンで追加します。
- **自動で移行します**：更新後の初回起動で、旧バージョンの各区画のフォルダ（サブフォルダ・選んでいた任意のフォルダを含む）の画像・動画を、ライブラリに集めて配置にします（同じ名前・同じ大きさのファイルは 1 つにまとめます。再生条件・回転も引き継ぎます）。元のファイルは消しません（同じドライブならリンクで、容量は増えません）。移行後は、元のフォルダにファイルを入れても、反映されません（管理画面から追加してください）。
- 「サブフォルダも含める」の設定は、なくなりました。

## コンテンツ画面とスケジュール画面（1.10.0 以降 / Android 1.11.0 以降）
管理画面に、**「🖼 コンテンツ」**と**「🗓 スケジュール」**のタブを追加しました（これまで「端末の設定」にあった、区画ごとの画像・動画の一覧と予約テロップは、ここへ移りました）。

**🖼 コンテンツ（ライブラリ）**
- 画像・動画を、ドラッグ＆ドロップで、まとめて登録します。登録先は、端末一覧でチェックした端末すべて（チェックがなければ、いま見ている端末）です。「登録と同時に配置する区画」を選ぶと、登録と同時にその区画に配置できます。
- 一覧で、検索、絞り込み（未使用・画像・動画）、複数選択（まとめて配置・削除）ができます。各ファイルに、配置の状況（どの区画に使っているか／未使用）が出ます。回転は、ファイルごとに設定します（どの区画で使っても同じ回転）。
- 削除は、ライブラリからの削除です（そのファイルの配置もすべて外れます）。

**🗓 スケジュール**
- 区画ごとに、**曜日 × 時間の週間表**で、いつ何を流すかを確認・編集できます。右のライブラリから、週間表の曜日・時間にドラッグすると、配置の編集画面が開きます（既定は 1 時間。条件は後から変えられます）。ダブルクリックでは、条件なし（常時）の配置から始められます。
- 帯をクリックすると、**配置の編集**ができます：区画、曜日・時間帯・期間（複数の条件を追加可）、画像の表示秒数（空欄なら共通の秒数）、**専用**。
- **専用**：この配置が有効な間は、専用の配置だけを流します（キャンペーン用）。専用が有効でないときは、通常の配置を、これまでどおり順に流します。時間帯が重なった通常の配置は、**交互に**流れます。
- 条件のない配置は「常時」として、表の上に出ます。期間だけの条件の配置も、常時に出ます。期間つきの帯は、点線で表示します。日をまたぐ時間帯（例：金曜の 22:00〜翌 02:00）は、2 日にまたがって表示します。
- 同じファイルを、複数の区画・複数の時間帯に配置できます。
- 表の下の「**この区画の再生順**」で、ドラッグ（または ↑↓）で、再生順を変えられます。「外す」は、配置を外すだけで、ファイルはコンテンツに残ります。
- 予約テロップの時刻（🔔）も、週間表に参考として表示します（予約の追加・変更は、同じ画面の下の「予約テロップ」）。
- 古いバージョンの端末は、新しい画面に対応していません（「アプリを更新してください」と表示されます）。

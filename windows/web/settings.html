サイネージの設定（この PC）

再生

全画面を閉じるには Alt + F4。タスクトレイのアイコンからも開けます。

画面分割・表示秒数・時計・テロップなどは「管理画面」で設定します。

画像・動画（ライブラリ）

画像・動画は、アプリ専用の保存場所（ライブラリ）に、まとめて保存されます。登録・削除と、どの区画で・いつ流すかは、管理画面から行ってください（フォルダを直接操作する必要はありません）。

天気予報の地域

予報は「東京地方」などの地域単位です。画面の見出しに市区町村名を表示します。

管理画面（別の端末から操作）

同じコードを持つ端末・管理画面だけが操作できます（PIN に加えて必要）。同じネットワークにある別のグループのサイネージは、端末一覧に出なくなります。英数字と - _ の 8〜32 文字。グループの全端末に、同じコードを設定してください（管理画面の「入れる端末」タブから、まとめて設定できます）。コードを忘れたときは、ここで解除できます。

管理画面で、操作できる端末を MAC アドレスで制限できます。誰も操作できなくなったときは、この PC のここ（またはタスクトレイ）から解除できます。

Android 版のサイネージと同じ PIN にしておくと、管理画面の端末一覧からまとめて操作できます。 初めて使うときに Windows のファイアウォールの確認が出たら「プライベート ネットワーク」を許可してください。
